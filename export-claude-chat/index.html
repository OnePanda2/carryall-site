How to export a Claude chat to PDF, Word or Markdown

Quick answer: open the chat on claude.ai, click Export next to Share, pick a format (PDF, Word, Markdown, Text or JSON) and click the big button. Files Claude created can be included too.

The ways Claude gives you

  • Copy a single answer with the copy button — one message at a time.
  • Export data (Settings → Privacy → Export data). Anthropic emails a download link to a ZIP of all your data in JSON — a backup, not a readable document.
  • Print the page — website layout, and long chats may not print completely.

The one-click way

  1. Install AI Chat Exporter: ChatGPT, Claude & Gemini (free).
  2. Open the chat on claude.ai.
  3. Click Export (next to Share), choose PDF, Word or Markdown and click the big button.

What the file keeps

  • Formulas as real math (Word gets editable equations), not raw code.
  • Tables, code blocks with colours, headings, lists and links.
  • Web sources as numbered [1] [2] links with a source list under each answer.
  • Names and sizes of files you uploaded; optionally the AI's thinking summary and the time of each message.
  • Only the messages you want: all, only the answers, only your prompts, or ones you pick.
  • Files and visuals Claude made (artifacts) can be added at the end of the file.

Is it private?

Yes. The file is made on your own computer, inside your browser. No chat content is sent to us — there is no CarryAll server. No account, no analytics, no ads. Details in the privacy policy.
